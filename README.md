\# CardGame (Prototype)



縦ラインの守りと、魔法・装備を使い分けて戦う、1対1のデジタルカードバトルです。

Unity 6 / C# で制作した、制作中のプロトタイプです。



\*\*プレイ（ブラウザ・PC向け）\*\*: 【itch.ioのURL】



\## ゲームの特徴



\- \*\*縦ラインの守り\*\*: 盤面は縦2×横3。同じ縦列の前にカードがいる間、後ろは攻撃されません

\- \*\*中央後列がリーダーを守る\*\*: 中央後列が倒れると、持ち主のリーダーに固定ダメージが入ります

\- \*\*魔法は守りを無視する\*\*: 盤面のどのカードにも、リーダーにも使えます

\- \*\*武器と防具\*\*: 自分のリーダーに装備します。武器を持つとリーダーも攻撃できます

\- \*\*2つの陣営\*\*: 勇者(魔法と装備が豊富)と魔王(弱いモンスターを多く出して数で押す)。CPUは反対の陣営を使います

\- \*\*デッキ切れ\*\*: 引くカードがないと、自分のリーダーにダメージ(1、2、3…と増加)



\## 設計のポイント



\- \*\*ルール処理(Core)と画面(UI)を分離\*\*: `PlayerState`、`BoardState`、`Combat` などのルール処理は、画面の部品に依存しません。将来のオンライン対戦で、行動を命令の形で扱えるようにするためです

\- \*\*カード効果を部品化\*\*: 効果を ScriptableObject として作り、組み合わせられる設計です(単体ダメージ、全体ダメージ、ドロー、召喚、複数効果の組み合わせ)。登場時、撃破時、魔法、武器の攻撃時で、同じ部品を使い回せます

\- \*\*CPU(SimpleAI)\*\*: 効果ごとに「おすすめ度」を返す仕組みで、魔法や装備の使い方を決めます。新しい効果を作っても、おすすめ度を書けば、CPUが使えるようになります



\## 主なコードの場所



| 場所 | 内容 |

|---|---|

| `Assets/Scripts/Core` | ルール処理(戦闘、盤面、プレイヤー、効果) |

| `Assets/Scripts/AI` | CPUの行動 |

| `Assets/Scripts/UI` | 画面の制御 |

| `Assets/Data` | カードや効果のデータ(ScriptableObject) |
